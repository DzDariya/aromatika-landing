# АРОМАТИКА

Адаптивный сайт-визитка концептуальной кофейни «АРОМАТИКА». Статический проект на HTML5, CSS3 и Vanilla JS — без сборщиков и тяжёлых библиотек.

**Слоган:** Вкус начинается с цвета.

## Публикация

- Исходный код: https://github.com/DzDariya/aromatika-landing
- Рабочий сайт: https://aromatika-landing-474.netlify.app

## Как запустить локально

Сайт можно открыть напрямую в браузере:

```
index.html
```

Рекомендуемый способ — через локальный HTTP-сервер (так корректно подгрузятся шрифты и все ассеты):

**Python 3**

```bash
cd F:\OpenCode\AROMATIKA
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

**Node.js (альтернатива)**

```bash
cd F:\OpenCode\AROMATIKA
npx serve .
```

Остановка сервера: `Ctrl + C`.

## Как работает главная механика

1. Исходное состояние: все три чашки в единственном блоке напитков монохромны, фон нейтральный.
2. Клик по чашке в коллекции:
   - выбранная чашка плавно переходит из `*_mono.png` в `*_master.png` (композиция не меняется);
   - остальные чашки остаются монохромными;
   - фоновая текстура плавно переходит в гамму напитка;
   - логотип меняется на соответствующий готовый файл;
   - появляется фраза о вкусе.
3. Клик по уже выбранной чашке возвращает нейтральную гамму и монохром.
4. Состояние хранится в памяти страницы: сохраняется при прокрутке и переходах между разделами, сбрасывается при перезагрузке.
5. Карточка «Не просто кофе. Маленькое впечатление» переворачивается по клику: `cafe_mono.png` сменяется цветным `cafe_main.png` и текстом о кофейне; повторный клик возвращает лицевую сторону.

Доступность: кнопки имеют `aria-pressed`, смена состояния озвучивается через `aria-live`, есть skip-link, клавиатурная навигация (включая Enter и пробел для переворота) и поддержка `prefers-reduced-motion`.

## Реализованные разделы

Главный экран, единственный блок с тремя напитками, интерактивная карточка «О кофейне» с 3D-переворотом, приглашение с переключателем вкусов, контакты с картой-заглушкой, футер. Изображения напитков находятся только в блоке коллекции: на чёрно-белой стороне карточки указано только название вкуса, на раскрытой цветной — состав и слоган. У карточки кофейни на лицевой стороне есть подсказка «Нажми, чтобы перевернуть». Навигация плавно прокручивает к разделам, на мобильных устройствах открывается компактное меню.

## Демонстрационные данные

Адрес, телефон, почта, Telegram и социальная сеть — демонстрационные значения из технического задания. Они не соответствуют реальным контактам. Карта намеренно выполнена визуальным блоком без координат. Ссылки на Telegram и социальную сеть показывают демо-уведомление.
